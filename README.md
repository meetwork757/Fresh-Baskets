# Fresh Baskets

Skip the market. Order your foodstuff and we deliver to your door.

This is a simple single-file web app for ordering fresh food items (vegetables, grains, tubers, protein, oils & spices) with WhatsApp checkout.

## Live Site
https://meetwork757.github.io/Fresh-Baskets/

To enable GitHub Pages (if not already):
1. Go to repository **Settings** → **Pages**
2. Source: Deploy from a branch
3. Branch: **main** / folder: **/ (root)**
4. Save

## Features
- Category tabs and product grid
- Add to cart with quantity controls
- Order summary with delivery fee
- Send order directly via WhatsApp
- Responsive design with dark mode support

Edit prices, items, seller phone (`SELLER`), and delivery fee (`FEE`) in the `<script>` section of `index.html`.
